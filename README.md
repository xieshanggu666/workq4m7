# 引力跳板 · 星际弹弓轨道规划游戏

一款以**引力弹弓（重力助推）**为核心机制的原创轨道规划游戏。玩家为深空探测器编排动作序列——点火变轨、耐心等待、在木星/土星等行星影响球内完成收紧的双曲飞掠——用最省的燃料把探测器送到火星、外太阳系，最终挣脱太阳引力飞出太阳系。

## 玩法

- **5 个关卡**由易到难：火星飞掠 → 小行星带穿越 → 木星引力捕获 → 土星远航（双弹弓接力）→ 星际逃逸
- 三种动作按顺序编排：
  - **等待**：让后续动作推迟 N 天执行
  - **点火**：指定方向（角度）与 ΔV 消耗燃料
  - **弹弓**：选择目标行星与近心点 b（正负决定绕行方向），探测器进入行星影响球时自动结算
- **物理引擎**：简化 N 体模型（太阳引力 RK4 积分 + 双曲飞掠公式），行星沿真实太阳系轨道参数做圆轨道运动
- **评分**：三星 ≤ 55% 燃料预算、二星 ≤ 80%、通关得星；最佳成绩存档（SQLite）
- **成绩记录**：每次发射落库为可追溯的执行档案（动作方案 + 轨迹 + 结算），成绩关联档案可回放、可载入方案继续调优；提交带幂等键，双击/重试/多标签页不会重复记分；兼容旧版存档
- **社区航线挑战**：设计者发布带燃料预算与里程碑的**版本化关卡**（每次发布生成不可变版本，旧版本仍可回放）；玩家提交**幂等结算**的飞行记录（服务端评分 + 幂等键去重）；成绩按**版本配置的多级审核流**逐级流转（每级可指定角色/审核人/时限，末级通过才上榜）后联动排行榜（按版本结算、每人取最佳）、轨迹回放与关卡解锁（内置关卡/前置挑战/累计星数三种解锁条件）
- **申诉与复核链路**：驳回/撤销的成绩可由玩家凭幂等键**申诉**（每成绩 2 轮、仅本人）；申诉去向按版本配置——进入**复核员裁决队列**，或**回到驳回时的审核级**由该级审核人重审（该级通过=推翻并继续向后流转、驳回=维持）；复核员还可对上榜成绩做事中**撤销/恢复**——撤销即出榜、关闭回放并级联回收解锁；提交→逐级审核→申诉→裁决→撤销/恢复全程落**不可变事件档案**，时间线可追溯；历史已审核成绩启动时补登链路事件；所有重复操作幂等
- **交互**：实时轨迹预览、滚轮缩放/拖动平移、回放动画、策略提示

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 一键启动（自动挑选空闲端口并打开浏览器）
npm run dev
```

启动后访问控制台输出的地址（如 `http://127.0.0.1:8072`），或直接按 `npm run dev` 自动打开的页面。

## 社区航线挑战

- **设计者**：「发布挑战」填写预算、时限、里程碑（近距飞掠/半径/捕获/弹弓后半径/逃逸）与解锁条件；可选勾选「自定义多级审核流」，为该版本配置 **1~5 个审核级**（级名称、所需角色初审员/复核员、指定审核人署名、审核时限 SLA）与**申诉去向**（复核员裁决 / 回到驳回级重审）。每次修改通过「＋ 发布新版本」生成不可变版本，关卡定义与审核流都锚定版本，成绩按版本结算排行榜
- **玩家**：进入挑战编排动作并发射，飞行记录由服务端结算后幂等提交（双击/重试不重复），进入该版本第 1 级审核队列；排行榜「我的提交」可查看当前所在审核级/时限，被驳回/撤销可发起申诉（2 轮）
- **审核人**：「🗂 审核工作台 → 审核队列」按级处理（可填写令牌、按级过滤）；某级**通过**进入下一级，末级通过成绩才进入排行榜、开放轨迹回放并联动解锁，任意一级**驳回**即落选。只有当前等待级可处理（多级须带 `stage`），指定审核人的级别仅名单内账号可操作；超过该级 SLA 的条目标红提示
- **复核员**：「申诉复核」页裁决走复核员队列的申诉（维持原判/推翻改判通过）；若版本配置申诉「回到驳回级」，申诉成绩会回到原审核级，由该级审核人在审核队列处理（通过=推翻并继续流转后续级、驳回=维持）。「终审管理」可撤销上榜成绩（立即出榜、关闭回放、级联回收解锁）或恢复。复核操作需 `X-Reviewer-Token`（本地默认令牌 `local-moderator`）
- **默认兼容**：不配置审核流的版本（含全部历史版本）按单级「初审 + 复核员受理申诉」运行，行为与旧版一致
- **可追溯**：每条成绩的「链路」展示提交→逐级审核（级名/级次/终审标记）→申诉→裁决→撤销/恢复的不可变事件时间线（操作者、角色、理由、时间、轮次）

## 关卡目标

| 关 | 名称 | 目标 | 燃料预算(km/s) |
| --- | --- | --- | --- |
| 1 | 火星飞掠 | 近距离飞掠火星 (< 0.18 AU) | 6.9 |
| 2 | 小行星带穿越 | 越过 4.2 AU | 15.6 |
| 3 | 木星引力捕获 | 木星弹弓后被捕获 | 17.3 |
| 4 | 土星远航 | 土星弹弓后远日点 ≥ 15 AU | 16.4 |
| 5 | 星际逃逸 | 挣脱太阳引力（飞出 40 AU 边界） | 19.9 |

## API

| 方法 | 路径 | 说明 |

| GET | `/api/challenges/{cid}/versions/{v}` | 指定版本完整定义 |

| GET | `/api/challenges/review_queue` | 审核队列：`?status=`、`?stage=N`（按审核级过滤）、带令牌时附 `can_review`；条目含当前级名称/角色/指定审核人/SLA 超时/申诉路由标记 |

| GET | `/api/challenges/submissions/{id}` | 成绩详情：末级通过后附带动作方案与轨迹（供回放），附审核级/时限/申诉入口 |

## 物理模型说明

- 距离 AU、时间 天、速度 AU/天（1 AU/天 ≈ 1731.5 km/s）
- 弹弓结算：入轨相对速度 v_inf、近心点 r_p 下，偏转角 δ = 2·asin(1/(1 + r_p·v_inf²/μ))，相对速度大小守恒（能量守恒）
- 行星间互不摄动；探测器在弹弓事件之间只受太阳引力（RK4）
- 近心点小于行星半径会解体；燃料耗尽或超时判负
