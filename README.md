# 引力跳板 · 星际弹弓轨道规划游戏

一款以**引力弹弓（重力助推）**为核心机制的原创轨道规划游戏。玩家为深空探测器编排动作序列——点火变轨、耐心等待、在木星/土星等行星影响球内完成收紧的双曲飞掠——用最省的燃料把探测器送到火星、外太阳系，最终挣脱太阳引力飞出太阳系。

## 玩法

- **5 个关卡**由易到难：火星飞掠 → 小行星带穿越 → 木星引力捕获 → 土星远航（双弹弓接力）→ 星际逃逸
- 三种动作按顺序编排：
  - **等待**：让后续动作推迟 N 天执行
  - **点火**：指定方向（角度）与 ΔV 消耗燃料
  - **弹弓**：选择目标行星与近心点 b（正负决定绕行方向），探测器进入行星影响球时自动结算
- **物理引擎**：简化 N 体模型（太阳引力 RK4 积分 + 双曲飞掠公式），行星沿真实太阳系轨道参数做圆轨道运动
- **评分**：三星 ≤ 55% 燃料预算、二星 ≤ 80%、通关得星；最佳成绩存档（SQLite）
- **成绩记录**：每次发射落库为可追溯的执行档案（动作方案 + 轨迹 + 结算），成绩关联档案可回放、可载入方案继续调优；提交带幂等键，双击/重试/多标签页不会重复记分；兼容旧版存档
- **社区航线挑战**：设计者发布带燃料预算与里程碑的**版本化关卡**（每次发布生成不可变版本，旧版本仍可回放），并可**按版本配置 1~5 级审核链**——每级指定级别名、角色（初审员/复核员）、指定审核人白名单与处理时限（SLA）；玩家提交**幂等结算**的飞行记录（服务端评分 + 幂等键去重），成绩**逐级流转**，全部级通过后才进入排行榜（按版本结算、每人取最佳）、开放轨迹回放并计入解锁
- **申诉进入正确队列**：玩家对第 L 级驳回（或终审后撤销）的成绩发起申诉（每成绩 2 轮、仅本人），成绩自动回到第 L 级审核队列，由该级指定审核人处理——维持原判回原状态，推翻原判继续向后流转（终审级推翻即上榜）；未配置审核链的版本沿用默认单级，申诉仍进复核员队列。**复核员**还可对上榜成绩做事中**撤销/恢复**——撤销即出榜、关回放并级联回收解锁；提交→逐级通过→申诉→复核→撤销/恢复全程落**不可变事件档案**，时间线可追溯；历史已审核成绩启动时补登链路事件；所有重复操作幂等
- **交互**：实时轨迹预览、滚轮缩放/拖动平移、回放动画、策略提示

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 一键启动（自动挑选空闲端口并打开浏览器）
npm run dev
```

启动后访问控制台输出的地址（如 `http://127.0.0.1:8072`），或直接按 `npm run dev` 自动打开的页面。

| 操作 | 方式 |

## 社区航线挑战

- **设计者**：「发布挑战」填写预算、时限、里程碑（近距飞掠/半径/捕获/弹弓后半径/逃逸）与解锁条件；可选在「审核链」中配置 **1~5 个审核级**：每级指定级别名、角色（初审员/复核员）、指定审核人（从已注册账号勾选，不选则该角色均可处理）与处理时限（小时）。每次「＋ 发布新版本」生成不可变版本，新版本默认沿用上版审核链，也可显式改配或回到默认单级；成绩按提交时版本的链路审核
- **玩家**：进入挑战编排动作并发射，飞行记录由服务端结算后幂等提交（双击/重试不重复），从第 1 级审核队列开始逐级流转；「我的提交」可查看当前所处级与时限，全部级通过后上榜/开放回放；被某级驳回或撤销可发起申诉（2 轮），申诉自动回到做出原判的那一级队列
- **审核人**：「🗂 审核工作台 → 审核队列」可按级（`?level=`）/超时（`?overdue=true`）筛选；每条显示「第 L/N 级 · 级别名 · 角色 · 指定审核人 · 时限」，仅该级指定审核人可处理（复核员可在任意级超时兜底）；「通过本级」流转到下一级，终审级通过才上榜；申诉回到该级的条目在同一队列裁决（推翻=继续流转，维持=回原状态）。未配置审核链的版本，缺省凭证即内置初审员一审
- **复核员**：「申诉复核」页仅处理默认单级链路的申诉（多级链路的申诉已在对应级队列）；「终审管理」可撤销上榜成绩（立即出榜、关闭回放、级联回收解锁）或恢复。复核操作需 `X-Reviewer-Token`（本地默认令牌 `local-moderator`）
- **可追溯**：每条成绩的「链路」展示提交→逐级通过→终审/驳回→申诉→撤销/恢复的不可变事件时间线（操作者、角色、级别、理由、时间、轮次）

## 关卡目标

| 关 | 名称 | 目标 | 燃料预算(km/s) |
| --- | --- | --- | --- |
| 1 | 火星飞掠 | 近距离飞掠火星 (< 0.18 AU) | 6.9 |
| 2 | 小行星带穿越 | 越过 4.2 AU | 15.6 |
| 3 | 木星引力捕获 | 木星弹弓后被捕获 | 17.3 |
| 4 | 土星远航 | 土星弹弓后远日点 ≥ 15 AU | 16.4 |
| 5 | 星际逃逸 | 挣脱太阳引力（飞出 40 AU 边界） | 19.9 |

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/system` | 天体参数、关卡信息、最佳成绩（含可回放记录 id） |

| POST | `/api/run` | 执行任务并评分（星级），执行档案落库并返回 `run_id` |

| GET | `/api/scores/{level_id}/records` | 某关成绩提交记录（追溯列表） |

| GET | `/api/challenges/{cid}/versions/{v}` | 指定版本完整定义（含该版本审核链） |
| POST | `/api/challenges/{cid}/preview` | 挑战轨迹预览（不评分、不落库） |
| POST | `/api/challenges/{cid}/run` | 挑战飞行结算：执行档案落库返回 `run_id`（未解锁 403） |

| GET | `/api/challenges/review_queue` | 审核队列：`?status=&level=N&overdue=true`；pending 含路由回本级的申诉，附当前级 stage（级别名/指定审核人/`due_at`/`overdue`） |
| POST | `/api/challenges/submissions/{id}/review?level=N` | 在当前审核级裁决：逐级通过（`review_advance`）→终审上榜，或本级驳回；按该级角色/指定审核人鉴权（`X-Reviewer-Token`） |
| GET | `/api/challenges/submissions/{id}` | 成绩详情：通过后附带动作方案与轨迹（供回放），附审核级/申诉轮次/入口 |
| GET | `/api/challenges/submissions/{id}/timeline` | 审核链路时间线：不可变事件档案 + 申诉单（提交/逐级通过/终审/申诉/撤销/恢复/历史补登） |

## 物理模型说明

- 距离 AU、时间 天、速度 AU/天（1 AU/天 ≈ 1731.5 km/s）
- 弹弓结算：入轨相对速度 v_inf、近心点 r_p 下，偏转角 δ = 2·asin(1/(1 + r_p·v_inf²/μ))，相对速度大小守恒（能量守恒）
- 行星间互不摄动；探测器在弹弓事件之间只受太阳引力（RK4）
- 近心点小于行星半径会解体；燃料耗尽或超时判负
